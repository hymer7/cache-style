考试记忆口诀

直接映射定一行，
全相联映射任意放，
组相联先定组，
组内再随便放。

地址格式：直接映射 Tag + 行号 + 块内地址；全相联 Tag + 块内地址；组相联 Tag + 组号 + 块内地址。

三种地址映射方式对比

映射方式 主存块能放哪里 地址格式 查找方式 替换范围 优点 缺点
直接映射 只能放到唯一 Cache 行 Tag + Index + Offset Index 定位一行，然后比较 Tag 固定行 简单、速度快、成本低 冲突多
全相联映射 Cache 任意一行 Tag + Offset 所有行同时比较 Tag 整个 Cache 灵活、冲突少 硬件复杂、成本高
组相联映射 固定组内任意一行 Tag + Set Index + Offset Set Index 定位组，组内比较 Tag 对应组内部 冲突较少、成本适中、实际常用 控制逻辑比直接映射复杂

考试易错点

直接映射取模的是 Cache 行数，不是主存块数。
组相联取模的是 Cache 组数，不是 Cache 行数。
几路组相联中的“几路”，表示每组有几行。
全相联没有行号字段。
Tag 不是用来定位的，而是用来判断 Cache 中是不是目标块。
Offset 只负责定位块内具体位置。
